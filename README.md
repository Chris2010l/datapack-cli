# datapack-cli

A lightning-fast, JSON-driven Minecraft datapack generator written in Go.

## Installation

Make sure you have [Go](https://go.dev) and [git](https://git-scm.com/install/) installed, then run:

```bash
git clone https://github.com/Chris2010l/datapack-cli.git
cd datapack-cli/
go install .
```

## Usage

Navigate to the directory where you want to create your datapack and just type:

```bash
datapack-cli
```
